# ICEM ACM Student Chapter Website
Official web portal for the **ICEM ACM Student Chapter**, Department of Artificial Intelligence & Data Science, Indira College of Engineering and Management (ICEM), Pune.

**Subdomain:** `https://acm.indiraicem.ac.in`

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

## Pages & Routes
- `/` - Landing Page & Key Highlights
- `/about` - Chapter Vision, Mission & Objectives
- `/committee` - Faculty Sponsor & Student Executive Council
- `/events` - Hackathons, Workshops & Seminars
- `/membership` - Student Membership Tiers & Benefits
- `/achievements` - Awards, Research Papers & Gallery
- `/dashboard` - Member Portal, Circulars, MoM, Treasury & Certificate Verification Vault
- `/login` - Member Portal Sign In & Registration
- `/contact` - Chapter Secretariat & ACM Global Portals
